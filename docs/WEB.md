# 웹 규칙 (liaison-web)

- **담당:** 웹 코드 소유자(`.github/CODEOWNERS`)가 직접 씁니다. 고칠 때는 PR로 올리고 웹 코드 소유자가 승인합니다.
- **공통 문서가 먼저입니다.** 모든 파트가 지킬 규칙은 `docs/common/`(liaison-docs)에 있습니다. 이 문서는 웹에만 해당하는 규칙을 적습니다. 공통 문서와 다르면 공통 문서를 따르고, 공통 규칙을 바꿀 일이면 liaison-docs에 PR을 올립니다.
- **공개 저장소입니다.** 사람 이름, 운영 서버 주소·계정, 비밀값을 적지 않습니다.

꼭 넣을 항목(PM 정리):
- App Router 폴더 구조
- 서버 컴포넌트·클라이언트 컴포넌트를 나누는 기준
- 데이터 불러오기와 캐시(학생 정보 응답은 `no-store`)
- 세션: HttpOnly 쿠키, 30분 미사용 시 다시 로그인, 25분 경고, 작성 중인 초안은 메모리에만
- API 오류는 문구가 아니라 `code`로 분기
- 화면 기준: 1920 디자인, 1536·1280 브레이크포인트
- PWA·웹 푸시·알림함
- 출시 전 기능의 메뉴·경로 숨김(출시 버전 게이트, 실제로 막는 곳은 서버)
- 분석·광고·추적 쿠키 금지(로그인 세션용 필수 쿠키만)
- 환경변수: `NEXT_PUBLIC_`에는 비밀값을 넣지 않음
- 테스트
- 실행 방법
